# ITEP 413 Midterm Practice Exam

A clean, responsive practice exam for ITEP 413: Information Assurance and Security.

The page is a single offline HTML app that works on desktop, Android, iPhone, and iPad browsers. It includes matching, multiple choice, true/false, and acronym review sections with instant scoring and answer feedback.

## About

This reviewer helps students practice common midterm topics such as OWASP risks, broken access control, IDOR, XSS, CSRF, OSI and TCP/IP concepts, wireless security, malware behavior, ISO/IEC 27001, PCI DSS, and important cybersecurity acronyms.

Built for DSD, with special credit to CAT.

## Features

- 100-item practice exam format
- Matching, multiple choice, true/false, and acronym sections
- Automatic scoring dashboard
- Answered progress bar
- Shuffle/restart mode
- Reveal-all answer key
- Acronym cheat sheet
- Print or save as PDF support
- Responsive layout for phones, tablets, laptops, and desktops
- Runs locally without installation or internet

## How To Use

Open `index.html` in any modern browser.

For the original named file, open `ITEP_413_Practice_Exam.html`.
