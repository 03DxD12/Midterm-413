About

This offline practice exam helps review core ITEP 413 midterm topics: OWASP risks, access control, OSI and TCP/IP concepts, wireless security, malware, ISO standards, PCI DSS, and common security acronyms. It works in modern mobile and desktop browsers without installation.

Test I: Matching

Nos. 1 to 10
Match each term in Column A with its meaning in Column B. Write the letter by choosing from the dropdown. Two extra meanings are distractors.

Test II: Multiple Choice

Nos. 11 to 50
Choose the best answer. You see the explanation right after you pick.

Test III: True or False

Nos. 51 to 80
Decide if each statement is true or false.

Bonus Test IV: Acronyms

Nos. 81 to 100
Choose what each acronym stands for.
